CHARLOTTE B. CHAVEZ — PORTFOLIO WEBSITE

FILES
- index.html: website content
- style.css: layout, colors, and responsive design
- script.js: mobile menu, project filters, email copy, and scroll progress
- assets/charlotte-portrait.png: portrait photo

HOW TO USE
1. Extract this ZIP file.
2. Open index.html in a browser to preview.
3. To publish with Netlify, log in to Netlify and drag the extracted project folder (the folder containing index.html) into the manual deploy area.
4. Keep the assets folder beside index.html so the portrait displays correctly.

EDITING
You can edit the text in index.html. Change colors and spacing in style.css.
The three project cards are clearly labeled as practice concepts/interface mockups, not deployed projects.
